# Reference data for regression tests

`ch4_sl_hr.dat.cw` and `graphene_pz_hr.dat.cw` were generated by `pw2cw` before the input/output
directory changes, so the tests check that the tight-binding Hamiltonian is unchanged.

- Code: commit `b00ebac` (v2.0.7), with only the unused `from matplotlib.pylab import MT19937` line
  removed from `symclosestwannier/cw/cw_model.py` so that it imports without matplotlib.
- Environment: Python 3.12.12, numpy 2.5.3, scipy 1.18.1, multipie 2.3.4, gcoreutils 1.2.0,
  h5py 3.16.0, macOS arm64.
- Inputs: `seedname.win/amn/eig/nnkp` from `others/examples/<seedname>/`, with the
  non-symmetrized `.cwin` settings in `tests/conftest.py` (`CWIN`) plus `write_hr = true` and
  `write_info_data = true`.
- Command: `pw2cw <seedname>` in a directory containing these files.

The tests compare matrix elements with an absolute tolerance of 1e-7, as the files are written
with 8 significant digits.

`wigner_seitz_w90.dat` holds the R vectors and degeneracies of a `seedname_hr.dat` written by
wannier90 (QE + wannier90 workflow on Materials Project structures; this one is mp-79, a hexagonal
cell whose lattice vectors are rounded to 7 digits in `seedname.win`), with the default
`ws_distance_tol` and `ws_search_size`. The lattice and `mp_grid` are in its header.
